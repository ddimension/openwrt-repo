Set up a device

Install ddimension-feed once, by name, from the tree that matches the device — it carries the feed address and the signing key, and keeps both current with apk upgrade:

apk --allow-untrusted \
  -X https://ddimension.github.io/openwrt-repo/stable/<release>/<arch>/packages.adb \
  add ddimension-feed
apk update
apk add wwand luci-app-wwand

stable = releases, main = development. A downloaded ddimension-feed.apk works too: apk add --allow-untrusted ./ddimension-feed.apk && apk update && apk add ddimension-feed — the last step turns the file install into a normal one, otherwise apk keeps it pinned and never upgrades it. Details: README.
